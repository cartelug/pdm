# Institutional motion, depth and responsive release (15 November 2026)

Implements the motion and responsive brief (Version 3, 13 November 2026) for the Astro/static lane. The six
homepage scenes now share one visual idea, a crimson thread that carries individual effort into shared
opportunity, and the motion engine was repaired so that every scene has one owner, a static final state
and a clean teardown. Content, wording, campaign facts, URLs and every protected file are unchanged.

Baseline: `main` at `99dcc7c` (also the rollback point). No dependency was added or upgraded.

## Not changed on purpose

- Walk for Education, Contribute, Faith in Motion, `js/`, `css/`, `api/`, `admin/`: no file in the protected baseline changed, so no presentation review was needed. The campaign lane keeps its own motion owner (`js/wfe-redesign.js`).
- No new library, video, canvas, image or font. No financial value, pledge figure or progress is animated or derived from scroll.
- The campus picture on the homepage now sits above the facts on phones, so a phone starts loading it (46 KB AVIF, the correctly sized 800 w source for a 351 px frame at 2×) on first load rather than a moment later. The home page stays within its budget.
