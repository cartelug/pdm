# The two house fonts: 26 October 2026

The owner supplied two font downloads and asked for them to be used across the whole site.

| Role | Font | File | Size |
| --- | --- | --- | --- |
| Headings, menus, buttons, labels, figures, anything bold | MTN Brighter Sans Bold | `assets/fonts/mtn-brighter-sans-bold.woff2` | 13.5 KB |
| Paragraphs, forms, captions | Sky Text Regular | `assets/fonts/sky-text-regular.woff2` | 14.5 KB |

Before: Archivo (34.9 KB) and Lexend (39.7 KB), 74.6 KB. After: 28.0 KB, so every page carries about 46 KB less font.

## How they are used

- **One source.** `src/design/tokens.json` (`fonts`) generates `css/brand.css` (hand-written pages) and
  `src/design/generated/fonts.css` (Astro pages). Tokens version 1.1.0.
- **Sky Text has one weight.** Its 600 to 900 weights are declared as the MTN Bold file, so a bold word inside a
  paragraph or a semibold label is always on brand and never a browser-faked bold.
- **Figures** are set in MTN Brighter Sans, whose digits are all the same width (tabular). Sky Text digits are
  proportional, so money and counters are never set in it.
- **Reading size.** Sky Text has a smaller x-height than the Lexend it replaces, so its faces carry
  `size-adjust: 106%`. Every stylesheet keeps its sizes and the 13 px floor still holds.
- **Fallbacks** are tuned to Arial and Arial Bold so text does not jump when the fonts arrive.
- **Legacy names.** Older stylesheets (some protected) still write Archivo, Lexend, Manrope, Inter Variable,
  Bricolage Grotesque, DM Serif Display, Instrument Serif, JetBrains Mono, Geist Mono Variable and Montserrat. Each is
  declared as an alias of one of the two files, so nothing else can be downloaded and no protected stylesheet was edited.
- **Graphics.** The downloadable HD graphics (`js/share-studio.js`) and the social share cards
  (`scripts/og-cards.cjs`) use the same two files.
- **Removed.** Archivo, Lexend, Inter, Instrument Serif, Geist Mono and Montserrat files, their licence files and the
  five `@fontsource` packages.
- **Test.** `tests/navigation/browser.cjs` loads six pages from both page families and fails on any third font
  file, on any family that is not a house font or an alias, on a heading that is not MTN Brighter Sans, on long text
  that is not Sky Text, and on a missing credit line.

## Credit and licence

Both downloads say: "You must credit the author", and give the line "Fonts made from Web Fonts is licensed by CC BY
4.0". Every page footer carries "Fonts: MTN Brighter Sans and Sky Text via Web Fonts, CC BY 4.0", linking to
onlinewebfonts.com. The notices are in `assets/fonts/mtn-brighter-sans-LICENSE.txt` and
`assets/fonts/sky-text-LICENSE.txt`.

**Open question for the owner.** The download page labels both fonts CC BY 4.0, but the font files name other
rights holders: MTN Brighter Sans is "Copyright 2017 Newlyn Works Limited. All rights reserved" (licensing:
newlyn.com/licensing), and Sky Text is "Copyright 2009 BSkyB Ltd". The same download's licence file also warns that some
fonts it hosts "may not allow embedding unless a commercial license is purchased". MTN Brighter Sans is also the
typeface of MTN, one of the mobile-money channels PCI asks supporters to use. This is the owner's decision. If the
terms cannot be confirmed, edit `fonts` in `tokens.json`, run `npm run tokens`, and the whole site changes in one step.

## Looking at it

- MTN Brighter Sans has a distinctive lower-case **t** (the crossbar has no right arm), so at small bold sizes a **t**
  can briefly read like an **r** or **f**. It is clear in context at heading sizes.
- The font's only ligature is the brand's own "Y'ello", so there are no surprise ligatures.
- The fonts have no arrow or tick glyphs; those fall back to the system font, as before.
