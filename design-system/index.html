One system.
Two brands.

Archivo for headings, menus, buttons, labels and figures. Lexend for paragraphs, forms and small text. No italics. This page is generated from src/design/tokens.json, the single source for the institutional site, Walk for Education and Faith in Motion.

Type scale

Archivo leads. Lexend reads.

Weight-only variable files (no width axis, so type can never look stretched), self-hosted, 74.6 KB together. Archivo carries tabular figures, so money and counts line up. Emphasis is weight or colour, never slant.

Space, shape, motion

A few values, used everywhere.

Three breakpoints only: 640, 900 and 1200 px, always min-width. Layout is mobile first. Touch targets are 44 px; nothing is smaller than 24 px.

Rules the build enforces

What every page must do.

  • Contrast from tokens.Every pair above is a test. A change that breaks one fails the build.
  • Fonts.Archivo and Lexend only, self-hosted, no italics, no third-party font host on public pages.
  • Responsive.320 px to 1536 px, landscape and 200% text, with no sideways scroll and nothing under 13 px.
  • Honest state.A figure is a target, pledged or verified. A date that is not confirmed is never shown.
  • One fact, one home.Campaign facts are read from the campaign record; a build check fails on any page that disagrees.
