# MTN Mobile Money mark

`mtn-logo.png` identifies the MTN Mobile Money channel used for Faith in Motion contributions (0772 495 733, Sylvia Kaawe, Chair Construction). Used as a small trust badge next to the payment details on the campaign pages and in PDF exports from the admin console.

The original supplied file had a solid yellow background; it has been keyed out to transparency (with edge colour decontamination, not just a hard cutout) so the mark drops cleanly onto both the light and dark payment-detail surfaces it's placed on.

Do not stretch, recolour, or crop the mark.
