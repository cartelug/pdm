# Walking Rotarian mark

`walking-rotarian-logo.jpeg` is the "Walking Rotarian" (VVR) emblem for the Faith in Motion walker, supplied for use on collections reports (PDF exports from the admin console). It is not used in the public site's own navigation or footer — see `../pamodzi/README.md` for the site's brand hierarchy.

Do not stretch, recolour, or crop the mark. Place it on a plain light surface.
