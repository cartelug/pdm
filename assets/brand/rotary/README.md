# Rotary partner mark

`rotary-logo.png` is the Rotary International wheel emblem, supplied for use as a partner identity on Faith in Motion collections reports (PDF exports from the admin console). It is not used in the public site's own navigation or footer — see `../pamodzi/README.md` for the site's brand hierarchy.

Do not stretch, recolour, or crop the wheel. Place it on a plain light surface.
