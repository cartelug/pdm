# Crimson programme illustration assets

Generated for the approved Pamodzi website direction on 14 October 2026.

- `hero-wide-*`: programme illustration with education as its primary scene, health, green development and cooperative participation as supporting themes. No project identity or completed-outcome claim is implied.
- `hero-mobile-*`: independently generated portrait recomposition using the selected wide image as a reference.
- `pillar-education-*`: sculptural book.
- `pillar-health-*`: protective curved forms around an ivory sphere.
- `pillar-climate-*`: folded leaf.
- `pillar-inclusion-*`: connected ascending ribbon structures.
- `connection-*`: shared-effort ribbon, book and leaf composition.

The five isolated illustrations have true alpha transparency. Exports trim only empty transparent bounds, normalise the presentation canvas and encode WebP; they do not recolour or redraw the generated objects. Responsive photographic exports preserve the selected image composition. The approved PCI logo is separate and remains unchanged.

All images were generated with the built-in image-generation tool. The shared brief calls for dignified Ugandan programme illustration, coherent crimson/burgundy materials, warm lighting, clear silhouettes, no emojis, no text and no invented project metrics. The mobile brief preserves the main teacher/pupil scene while repositioning secondary programme content. Individual pillar briefs require distinctive silhouettes within the same material family.

`fonts/` contains the self-hosted font distributions used by the legacy campaign presentation layer and their supplied licenses. Astro bundles the institutional font distributions from the pinned npm dependencies.
